# Mexicanism gold set — from the Spanisch::Mexicanismos deck (Monterrey).
#
# One lemma per line. `#` comments, optional tab and POS tag. Scored by
# `gloss_trial.py --gold`, over the entries a book actually contains.
#
# The deck records *cards*, which are phrases and inflected forms; the lexicon
# holds spaCy lemmas. The derivation below is not mechanical, and three kinds of
# entry were treated differently:
#
#   Single words carry over as they are: platicar, chela, elote.
#
#   Slashed pairs become both members: "Güey / wey", "Morro / morra".
#
#   Words whose Mexican reading is a *different part of speech* from their
#   ordinary one carry a POS pin. "¡Aguas!" is the interjection, not water;
#   without the pin, every occurrence of `agua` in a novel would be scored as a
#   mexicanism the model failed to flag, and the recall figure would be a
#   measure of how often the book mentions water.
#
# Entries left out are listed at the bottom with the reason. They are not
# oversights and re-adding them would make the score worse, not stricter.

# Every entry carries a tag. The tag is what a build would ask about — the
# lexicon key is `(lemma, pos)` — and it is also what the direct probe sends, so
# leaving it off would mean guessing a tag and then scoring the model on the
# guess.

# — left out, and why ————————————————————————————
#
# Multi-word cards. The lexicon is keyed on single lemmas, so these can never
# match; the mexicanism is the phrase, not any word in it.
#   ¿Qué onda?      · ¡No manches!   · Ni modo
#   Carne asada     · Hacer el paro  · Estar crudo
#
# Single words whose Mexican sense shares a part of speech with a common
# ordinary sense. Scoring these would punish the model for being right:
#   fresa   — posh vs. strawberry, both NOUN
#   sale    — "deal" vs. the verb salir, and spaCy lemmatizes it to salir
#   regar   — "to screw up" (la regué) vs. to water, both VERB
#   crudo   — hungover vs. raw, both ADJ
#   paro    — favour vs. work stoppage, both NOUN
#   onda    — in ¿qué onda? only; the bare noun is not the mexicanism
